# 🚀 Senior Shopify Developer Portfolio

Professional portfolio website for a Senior Shopify Developer & E-commerce Specialist.

## ✨ Features

- 🎨 Modern dark theme with gradient accents
- ⚡ Fully responsive (mobile, tablet, desktop)
- 🎭 Custom cursor with interactive effects
- 📊 Animated counters and scroll reveals
- 💻 Code window showcase
- 📱 Mobile-first navigation
- 🚀 Optimized for performance (GitHub Pages ready)

## 🛠️ Tech Stack

- HTML5 (Semantic)
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter, JetBrains Mono)

## 🚀 Deployment to GitHub Pages

1. Create a new repository on GitHub
2. Upload all files to the repository
3. Go to **Settings → Pages**
4. Select **main** branch as source
5. Your portfolio will be live at `https://yourusername.github.io/repo-name/`

## 🎨 Customization

Edit these files to personalize:

- `index.html` — Content, text, project details
- `style.css` — Colors (top of file, `:root` variables)
- `script.js` — Animations and interactions

### Color Variables (in style.css)

```css
:root {
    --accent: #00d4aa;       /* Main accent */
    --accent-purple: #7c3aed; /* Purple */
    --accent-blue: #3b82f6;   /* Blue */
}
